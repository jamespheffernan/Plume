Aspect 1

What should the orb do at the boundary?

The current system uses one raised-cosine `raw` value for scale, fill, halo, and digit color. That gives coherence, but it makes the handoff feel mathematical. The revised bar is simple: full inhale fills the vessel; exhale empties it.

Depth verdict
6

Strong premise, under-choreographed edges

The persistent ring gives the breath a home. The guide never vanishes. The flaw is that full hold and empty hold can read as frozen UI rather than different kinds of stillness.

What to keep
  • Keep active scale as `0.30 + 0.70 * raw`.
  • At full inhale, fill reaches the ring. It should not sit as a smaller disc inside the vessel.
  • Keep inhale fill by roughly raw `0.10` and exhale fade by roughly raw `0.20`.
  • Keep the persistent ring and the white-to-ink digit crossfade.
  • Keep one visible phase label below the orb.

Aspect 2

How should Plume tell you what changed?

The range pass rejected the obvious move: add more instruction. The better premise is that the orb carries time, the label confirms the current phase, and audio or haptics mark the boundary only when the user enabled them.

Direction Changed premise Strength Risk Best context
Motion carries boundary The orb is the instruction. Calm and uncluttered. Too subtle for beginners. Default session.
Future echo Show the next state before it arrives. Rich signal without copy. Can double the orb. Visual-first users.
Countdown release Remove measurement near the change. Deep calm. Less exact. Experienced users.
Sensory lead-in The body receives the cue. Works with eyes closed. Depends on settings and hardware. Audio or haptic users.
Adaptive intensity Different routines need different edges. Better fit per pattern. More branching and QA. Full product system.
Feedback depth

Orb-led handoff

The current hierarchy is right. The digit lives inside the orb. The phase label sits below and confirms. The boundary cue belongs to audio or touch, not more visible words.

  • At 900ms remaining, fade the current label to about 60%.
  • At the boundary, swap to the next label with the existing short fade.
  • Return label opacity to full over about 250ms.
  • Never show zero. The breath turns; it does not stop.
Accessibility

Give VoiceOver the next phase, not the screen

Sighted users should still see one label. VoiceOver can carry the near-boundary context without adding visible copy.

  • Orb label: current phase.
  • Value: "3 seconds remaining."
  • At 2 seconds or less, add "next inhale", "next hold", or "next exhale".
  • Avoid spoken announcements every animation frame.
Prototype order
1

Decoupled vessel

Refine the existing concept first. Make full inhale fill the vessel, then add boundary windows, smoothstep thresholds, halo lag, ring catches, delayed labels, and better accessibility values.

2

Add a previous-state afterimage around full and empty holds. This gives the boundary a material handoff while preserving the current orb and label hierarchy.

3

Liquid meniscus

Test only if the refined vessel still feels too abstract. It is the strongest replacement, but it changes the visual language more than the app likely needs.

Implementation surface

Where this would land

  • `SessionView.pupilStage`: compute visual channels instead of using one shared `raw` path.
  • `breathOrb`: accept ring opacity, halo opacity, fill opacity, and digit blend separately.
  • `BreathState`: expose next phase and boundary proximity, or derive them safely in the view.
  • `BreathHaptics`: shape the first 100ms of inhale and exhale as pickup, not command.
Discard

Strong ideas that should not ship first

These ideas were useful because they define the boundary. They lose because they make Plume louder, more instructional, or less precise.

"Next: Exhale"

Clear, but it creates a second voice on the screen.

Visible progress ring

The orb already shows progress. A second meter adds machinery.

Final-second tick

It turns the handoff into an alert.

Fill before motion

It recreates the dead zone the current fix removed.

Zero digit

It feels like expiration. The breath should turn.
