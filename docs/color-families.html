Six colour families for the Plume breathing app, each locked to one OKLCH brightness and saturation signature with only hue rotating, arranged across the warm-to-cool and light-to-dark temperature map. Each theme shows paper, an ink type specimen, the muted tone and the accent, with hex values and an AA contrast pass.

Colour Families

Each family holds one brightness and one saturation fixed and turns only the hue, so the four siblings always belong together. The families spread across the temperature map — warm, cool, neutral; light to dark — so you can find a lane before we refine. Built on the Interface Craft colour method; every palette clears WCAG AA.
